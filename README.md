# РЕЗМЕТАЛЛ — сайт металлообработки

Современный многостраничный сайт производственной компании **РЕЗМЕТАЛЛ**: лазерная резка, гибка, сварка, ЧПУ и покраска.

## Страницы

| Файл | Раздел |
|------|--------|
| `index.html` | Главная |
| `services.html` | Услуги |
| `projects.html` | Проекты |
| `about.html` | О компании |
| `contacts.html` | Контакты и форма заявки |

Общие стили: `css/styles.css`. Навигация, мобильное меню, анимации появления и форма: `js/main.js`.

## Запуск

```bash
chmod +x create-site.sh
./create-site.sh
```

Скрипт проверяет структуру и поднимает локальный сервер на `http://127.0.0.1:4173`.

Либо:

```bash
python3 -m http.server 4173
```

Затем откройте `http://127.0.0.1:4173` в браузере.
